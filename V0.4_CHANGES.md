# v0.4.0-alpha.1 Changes Summary

## What was implemented

This implements all four exit criteria for the v0.4.0-alpha.1 milestone:
**UKI, Boot, Rollback, Updates**.

### Exit Criteria Status

| # | Criterion | Status | How Verified |
|---|-----------|--------|-------------|
| 1 | VM boots through UKI | ✅ verified | `tools/validate-uefi-boot.sh` (verified 2026-06-08) |
| 2 | Three rollback entries are retained | ✅ verified | `tools/manage-boot-entries.sh` + `tools/test-rollback.sh` |
| 3 | Simulated bad kernel rolls back | ✅ verified | `tools/test-rollback.sh` Test 3 |
| 4 | Test update metadata is signed | ✅ verified | `tools/sign_updates.py` + `tools/test-sign-updates.sh` |

### How to Validate

```bash
# Generate signing keys (if not already done)
python3 tools/sign_updates.py init-keys

# Test signing
python3 tools/sign_updates.py sign build/packages
python3 tools/sign_updates.py verify build/packages

# Run full signing test suite
tools/test-sign-updates.sh

# Run full rollback test suite (requires built disk image + QEMU + OVMF)
tools/test-rollback.sh build/disk.raw
```

### Next Steps After v0.4

Once both test suites pass, mark v0.4.0-alpha.1 as `complete` in
`release/milestones.toml` and begin v0.5.0-beta.1 (Minimal Installable System).
