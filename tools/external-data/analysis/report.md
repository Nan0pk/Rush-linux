## 2. OSADL Cyclictest — Latency-Critical Class Bounds


*Most RT-kernel systems achieve max cyclictest < 100 µs. optid's latency-critical contract bound (10 µs cyclictest max) is very tight — only achievable on tuned RT kernels with CPU isolation. Recommend softening to 50 µs for a production-realistic default.*
