# Support

If you need help with Rush Linux, please use the following resources:

## Discussions
The best place to ask questions, suggest ideas, or showcase your projects is our [GitHub Discussions](https://github.com/Nan0pk/Rush-linux/discussions).

## Issues
If you have found a bug or have a specific feature request, please check if there is an existing [issue](https://github.com/Nan0pk/Rush-linux/issues). If not, feel free to open a new one using the appropriate template.

## Documentation
Please refer to the [docs/](https://github.com/Nan0pk/Rush-linux/tree/main/docs) directory for detailed documentation on architecture, design decisions, and usage.
