# docs/inbox — Unsorted drafts

Drop transient notes, in-progress reports, and agent-generated analyses
here. Files in this directory are **not** registered in `docs/docmap.toml`
and are not checked by CI validators.

Before merging to main:
- promote the file to the correct `docs/` subdirectory, OR
- delete it if it served its purpose.

See `docs/documentation-policy.md §Root Directory Hygiene` for the full rule.
